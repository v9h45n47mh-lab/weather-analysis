# Reduced radar map

Public-domain Natural Earth geometries, clipped to the DWD coverage region and simplified. Only rivers, country borders and selected towns with at least 50,000 inhabitants are retained. The rendered view has at most four city labels, no roads, buildings or elevation shading.

Sources: Natural Earth 1:10m rivers/lake centerlines, admin-0 land boundaries and populated places simple (5.x), downloaded 2026-11-19 from the official project repository:

- https://github.com/nvkelso/natural-earth-vector/tree/master/geojson
- https://www.naturalearthdata.com/about/terms-of-use/

No user locations are stored in this file. All map coordinates are projected dynamically for the current authorised user's location.
